Virtualisation DevOps Cloud

Infrastructure Proxmox VE

Infrastructure virtuelle sous Proxmox VE : VMs Linux et Windows, VLANs, services applicatifs et sauvegardes planifiées.

Réseau découpé en VLANs et filtré par pfSense

Objectifs

Reproduire chez moi un environnement de production d'entreprise pour m'entraîner à l'administrer.

Réalisation technique

Installation et configuration du bare-metal Proxmox VE. Création et gestion de machines virtuelles (Windows/Linux) et de conteneurs LXC. Mise en place du routage inter-VLANs et du filtrage réseau via un pare-feu pfSense virtualisé.

Résultats/Apports

Le réseau du lab est découpé en VLANs et filtré par pfSense. Je m'en sers pour tester des déploiements, des attaques et des défenses sans toucher à mon réseau domestique.

  • Simulation d'une petite infrastructure d'entreprise avec AD, serveur web et supervision centralisée.
  • Test de procédures d'exploitation : snapshots, reprise après incident, segmentation réseau.
Proxmox VE KVM/QEMU LXC Ubuntu pfSense Grafana
Windows Server Active Directory

Homelab Active Directory

Déploiement d'un environnement Windows Server 2022 avec Active Directory, DHCP/DNS intégrés, sécurisation et gestion des accès.

GPO de sécurité et quotas par service

Objectifs

Apprendre à administrer et sécuriser un parc Windows depuis un contrôleur de domaine.

Réalisation technique

Installation de Windows Server 2022 et promotion en contrôleur de domaine. Implémentation des rôles DHCP et DNS. Création d'une arborescence d'Unités Organisationnelles (OU) et déploiement de GPO (restrictions locales, lecteurs réseau, politique de mots de passe).

Résultats/Apports

Le domaine fonctionne comme un réseau d'entreprise : à la connexion, chaque poste reçoit son adresse IP, ses lecteurs réseau et ses restrictions. J'ai écrit un script PowerShell qui crée les comptes utilisateurs automatiquement.

  • Création d'utilisateurs/groupes simulant plusieurs services métiers (RH, finance, support).
  • Mise en place de GPO de sécurité et d'un serveur de fichiers avec quotas par service.
Windows Server 2022 Active Directory GPO DHCP/DNS PowerShell
Linux Sécurité Web

Serveur web sécurisé

Déploiement d'un stack LEMP sécurisé (Nginx, MySQL, PHP) avec configuration pare-feu, certificats TLS et durcissement du système.

Note A sur SSL Labs

Objectifs

Héberger un service web en respectant les bonnes pratiques de cybersécurité et de durcissement (hardening).

Réalisation technique

Déploiement d'une stack LEMP (Nginx, MySQL, PHP) sur Ubuntu Server. Configuration stricte du pare-feu UFW, mise en place de certificats SSL/TLS via Let's Encrypt, et protection contre le brute-force avec Fail2ban. Revue des droits système.

Résultats/Apports

Note A sur SSL Labs. Fail2ban bannit automatiquement les adresses IP qui accumulent les échecs de connexion.

  • Mise en ligne d'un site HTTPS accessible depuis Internet avec règles de filtrage strictes.
  • Blocage des attaques par force brute avec Fail2ban, journalisation et revue de configuration.
Ubuntu Server Nginx MySQL SSL/TLS UFW Fail2ban
Monitoring Docker

Stack monitoring & alerting

Supervision du lab avec Prometheus, Grafana et Alertmanager, déployés en conteneurs Docker.

Alertes sur seuils CPU, RAM et disque

Objectifs

Être prévenu d'un problème sur le lab avant de le constater moi-même.

Réalisation technique

Déploiement via Docker Compose de Prometheus (collecte des métriques via Node Exporter), Grafana (création de tableaux de bord personnalisés) et Alertmanager (gestion des notifications). Configuration des seuils d'alerte (CPU, RAM, disque).

Résultats/Apports

Les tableaux de bord Grafana montrent l'état de chaque machine du lab. Alertmanager envoie une notification dès qu'un seuil CPU, RAM ou disque est dépassé.

  • Suivi des performances des serveurs et des services.
  • Alerte automatique dès qu'un seuil est dépassé.
Prometheus Grafana Docker Alertmanager Node Exporter
