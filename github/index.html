portfolio-kader

Public JavaScript Mis à jour en oct. 2026

Le site que vous consultez : un portfolio statique en HTML, CSS et JavaScript, hébergé sur GitHub Pages, dont une partie du contenu se régénère toute seule.

Objectifs

Présenter mon parcours sans framework ni étape de build, avec un site rapide et simple à maintenir.

Réalisation technique

Un script Python relit des flux RSS et réécrit la section Veille ; un workflow GitHub Actions le lance les 1er et 15 du mois. Le CV en PDF est lui aussi généré par script. Une version « jeu » en pixel art lit la page principale au chargement, sans dupliquer le contenu.

Résultats/Apports

Un site qui reste à jour sans intervention manuelle, et une première pratique de l'intégration continue sur un projet réel.

  • Veille technologique mise à jour automatiquement par GitHub Actions.
  • CV PDF généré par script, thème clair/sombre, version jeu en pixel art.

bot-carburant

Privé Python Mis à jour en oct. 2026

Bot Discord qui publie chaque matin le prix de l'essence et du diesel en France, à partir des données ouvertes de prix-carburants.gouv.fr.

Objectifs

Recevoir chaque jour une information utile sans avoir à la chercher, et sans payer d'hébergement.

Réalisation technique

Deux modes : une publication quotidienne planifiée par GitHub Actions via un webhook Discord, et un bot interactif avec les commandes /prix et /moyenne. Le lieu et les carburants suivis se règlent par variables du dépôt. D'autres modules réutilisent le même principe : alerte sur les bons plans Dealabs toutes les heures et relevé quotidien du prix des vols.

Résultats/Apports

Pratique des API ouvertes, des webhooks, de la planification par cron et de la gestion des secrets dans GitHub Actions.

  • Publication quotidienne planifiée par GitHub Actions, sans serveur.
  • Modules complémentaires : alertes bons plans et suivi du prix des vols.

discord_bot

Privé Python Mis à jour en avr. 2026

Bot Discord qui surveille les nouvelles offres d'alternance et les publie dans un salon, classées par secteur.

Objectifs

Être prévenu des nouvelles offres dès leur parution, directement sur Discord.

Réalisation technique

Bot écrit avec discord.py : une tâche planifiée interroge régulièrement les offres, ne garde que les nouvelles et les publie sous forme de messages enrichis, colorés selon le secteur. Quatre commandes permettent de lancer une recherche, d'afficher des statistiques, de réinitialiser l'historique et d'obtenir de l'aide. Le bot est déployé sur Render.

Résultats/Apports

Mon premier bot hébergé en continu : gestion d'une tâche de fond, d'un état persistant et d'un déploiement décrit dans un fichier de configuration.

  • Recherche planifiée et publication des seules nouvelles offres.
  • Commandes de pilotage et déploiement sur Render.
